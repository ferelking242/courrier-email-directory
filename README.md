# Courrier — annuaire d’adresses

Site statique conçu pour GitHub Pages. Les adresses sont regroupées par
première lettre, triées alphabétiquement, filtrables par recherche et copiées
au presse-papiers lorsqu’on les touche.

Le site contient uniquement des adresses email — aucun mot de passe, note,
identifiant Telegram ou fichier de session.

## Publication

La source de publication GitHub Pages est la racine de la branche `main`.
